# Soho Gatherings 🎉

A stylish, editorial-inspired landing page for gatherings, entertaining, and event design.

The page features event stories, hosting ideas, venue inspiration, social content, and plenty of celebratory atmosphere.

## Built With

- HTML
- CSS
- Vanilla JavaScript
- Google Fonts

## View the Project

No installation or build process is required.

1. Download or clone the repository.
2. Open `index.html` in a browser.

For the best local-development experience, you can also serve the folder with an extension such as Live Server.

## Project Status

This project is currently a work in progress. The main page structure and visual styling are underway, while interactive features and some placeholder content still need to be completed.
